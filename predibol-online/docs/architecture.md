# Architecture

Frontend:
- Next.js 16

Authentication:
- Supabase Auth
- Google OAuth

Database:
- PostgreSQL (Supabase)

Storage:
- Supabase Storage

Background Processing:
- External scripts

No custom backend.

No Express.

No NestJS.

No server APIs except Next.js server actions when necessary.

Business logic should be implemented using:
- Supabase
- RLS
- Database queries
- External automation scripts
