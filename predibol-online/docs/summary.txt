 Fase 2 — Core Prediction System (completada en esta sesión)

Match listing:
- Listado de los 104 partidos desde wc26.json agrupados por fecha
- Selector de día con tabs navegables (por defecto al primer día con partidos)
- Cada match card muestra: group badge, estanderas, nombres de equipos
- Banderas renderizadas vía flagcdn.com CDN con fallback a emoji unicode
- Placeholders para partidos de knockout (W73, 2A, etc.) manejados sin bandera
- Soporte para partidos sin datos de equipo

- Inputs numéricos (0-30) para goles de cada

- Botón "Save" por partido con feedback visual (✓ Saved! / error)
- Valores pre-rellenados si ya existe predicción guardada
- Server Action savePrediction() con validación del lado servidor

Deadline locking:
- Bloqueo 10 minutos antes del kickoff (según business-rules.md)
- Timezone: America/La_Paz (UTC-4)
- Cálculo vía Date.UTC() para evitar bugs de parsing
- Tarjeta cambia a borde ámbar + badge "Locked"
- Inputs deshabilitados en modo solo lectura
- Muestra predicción guardada o "No prediction was saved"
- Validación server-side que rechaza saves post-deadline

Flujo de acceso (arreglado):
- portal/layout.tsx: no autenticado → /, whitelist fail → /unauthorized, no pago → /payment-pending, pago OK → acceso
- payment-pending/page.tsx: re-verifica haspaidentry en cada carga + botón "Verify Payment"
- getHasPaidEntry() defensivo: soporta ambasna PostgreSQL

Script de seed:
- scripts/seed-matches.ts — idempotente, upsert de 104 partidos desde JSON
- pnpm seed-matches para ejecutar
- Requiere SUPABASE_SERVICE_ROLE_KEY en .env.local
